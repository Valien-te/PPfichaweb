# Progress — guía de uso

Barra de progreso. Para mostrar avance. El componente vive en tu proyecto: instálalo con `create-lexy add progress` y edítalo con libertad.

## Import

```tsx
import { Progress } from "@/shared/components/base/Progress";
```

## Uso básico

```tsx
<Progress />
```

## Props

Consulta la story en Storybook para ver las props disponibles.

## Reglas

- Usa Progress según el propósito descrito.
- No abuses de este componente en contexts donde no aplica.
